Every key the website needs, and where to get it

Five environment variables power the booking pipeline and the Google-reviews section. Work through them in order — the first three make the form earn money; the last two are optional until your Google Business Profile is live.

Without 1–3 the form still shows the WhatsApp button, but no lead row is written anywhere. Without 4–5 the reviews section simply stays hidden.

01

WhatsApp number

1 min

Where "Send on WhatsApp" delivers the booking. Digits only, country code first, no + or spaces. For the shop's confirmed number:

NEXT_PUBLIC_WHATSAPP_NUMBER=919886844485
02

Shared secret

1 min

A password you invent. The website sends it with every Sheet write and the Apps Script refuses requests without it, so strangers can't spam your Sheet. Generate a strong one:

openssl rand -hex 24

Keep the output handy — the same value goes in this env var and in the Apps Script's script property in step 03.

03

Sheet webhook

15 min

A tiny Google Apps Script attached to your Sheet receives each booking and appends a row, timestamped in Asia/Kolkata.

Create the Sheet

Open sheets.new, name it iProtectCare Leads, and put these headers in row 1:

Timestamp | Date | Time | Device | Model | Issue | Notes | Name | Phone | Email | Address | PIN | Consent | Source Page

Attach the script

In the Sheet: Extensions → Apps Script. Delete the placeholder and paste:

function doPost(e) {
  var props = PropertiesService.getScriptProperties();
  var data = JSON.parse(e.postData.contents);
  if (data.secret !== props.getProperty('SHARED_SECRET')) {
    return ContentService.createTextOutput(JSON.stringify({ ok: false }))
      .setMimeType(ContentService.MimeType.JSON);
  }
  // Date/time formatted here in Asia/Kolkata — the server runs UTC.
  var tz = 'Asia/Kolkata';
  var now = new Date();
  SpreadsheetApp.getActiveSpreadsheet().getSheets()[0].appendRow([
    data.timestamp || now.toISOString(),
    Utilities.formatDate(now, tz, 'dd MMM yyyy'),
    Utilities.formatDate(now, tz, 'HH:mm'),
    data.device, data.model, data.issue, data.notes,
    data.name, data.phone, data.email,
    data.address, data.pin, data.consent, data.sourcePage
  ]);
  return ContentService.createTextOutput(JSON.stringify({ ok: true }))
    .setMimeType(ContentService.MimeType.JSON);
}

Set the secret & deploy

  1. Project Settings (gear icon) → Script properties → add property SHARED_SECRET with the value from step 02.
  2. Deploy → New deployment → Web app. Execute as Me; who has access: Anyone — the shared secret is the real gate.
  3. Authorize when asked, then copy the Web app URL ending in /exec. That URL is SHEETS_WEBHOOK_URL.

Test it

curl -sL -X POST "https://script.google.com/macros/s/XXXX/exec" \
  -H 'content-type: application/json' \
  -d '{"secret":"YOUR_SECRET","timestamp":"curl test","device":"iPhone",
       "model":"Test row","issue":"Ignore me","notes":"","name":"Jane Doe",
       "phone":"+91 9000000000","email":"jane.doe@example.com","address":"",
       "pin":"","consent":"yes","sourcePage":"/curl-test"}'

Expect {"ok":true} and a new row in the Sheet. Delete the test row after.

Editing the script later? Use Deploy → Manage deployments → edit → new version. Creating a brand-new deployment changes the URL and breaks the website until you update the env var.
04

Google reviews keys

15 min

Both values — GOOGLE_PLACE_ID and GOOGLE_PLACES_API_KEY — come from the interactive wizard in the repo. It opens each Google page, captures what you paste, saves it to .env.local, and verifies against the live API:

bash scripts/setup-google-reviews.sh

Run it in a real terminal window (not through the chat prompt — it needs your keyboard). It covers: verifying the Business Profile, copying the Place ID from Google's finder, enabling Places API (New), and creating a restricted API key.

Where the values go

Local development — all five in .env.local (git-ignored, never committed). Restart npm run dev after editing.

SHEETS_WEBHOOK_URL=https://script.google.com/macros/s/XXXX/exec
SHEETS_SHARED_SECRET=paste-from-step-02
NEXT_PUBLIC_WHATSAPP_NUMBER=919886844485
GOOGLE_PLACE_ID=ChIJ....
GOOGLE_PLACES_API_KEY=AIza....

Production — Vercel dashboard → iprotectcare-website → Settings → Environment Variables → add each name and value for all environments, then Deployments → ⋯ → Redeploy so the live build picks them up.

Final check

  • Submit a test booking on /book (Jane Doe data) — success screen appears and a row lands in the Sheet.
  • Tap "Send on WhatsApp" — the prefilled chat targets the shop number.
  • The reviews section shows on the homepage once the Business Profile has at least one real review (Google's API returns up to 5; the section links to the rest).
